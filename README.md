# pathfinding_visualizer

A Python project to visualize common pathfinding algorithms (BFS, Dijkstra, A*, and others) running step-by-step on an interactive grid.

## Setup

```bash
python -m venv venv
venv\Scripts\activate   # Windows
pip install -r requirements.txt
```

## Run

```bash
venv\Scripts\python main.py
```
